# Generic Scaffold

This folder is used for stacks not yet explicitly supported by SEprocess.

## Manual Setup Steps
1. Initialize the project (git init, npm init, etc.).
2. Create a virtual environment or container.
3. Install quality tools (Linters, Test Runners).
4. Define the directory structure (src/, tests/, docs/).
5. Create a `dev-setup` script if possible to automate these steps for the next dev.
